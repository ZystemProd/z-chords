How to Use

Type chord names like C, Dm, G7, or Bbmaj7 and press Enter or click Add. Use Add Custom Chord to design voicings and mark left hand notes.

  • Sections help you organize parts of a song.
  • Use the arrows on each card to change inversion.
  • Toggle Two Hands to widen the keyboard and show bass notes.
  • Export your layout to PDF with the download button.

Shortcuts

  • Enter: Add chord from input
  • Ctrl/Cmd+K: Focus chord input
  • H: Toggle two-hands mode
  • G: Toggle instrument (Piano/Guitar)
  • T: Toggle theme
  • Ctrl/Cmd+Shift+P: Export to PDF
